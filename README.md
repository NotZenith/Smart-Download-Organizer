# 📂 Smart Download Organizer

A simple Python automation tool that automatically organizes files in a folder (like Downloads) into structured categories.

## ⚡ What it does

- 📁 Scans a given folder
- 🖼️ Sorts images, videos, documents, archives, and code files
- 🗂️ Creates folders automatically if they don’t exist
- 🚚 Moves files into their correct categories
- 🧠 Leaves unknown file types in "Others"

## 🧩 Categories Supported

- Images → `.png .jpg .jpeg .gif .webp`
- Videos → `.mp4 .mkv .mov`
- Documents → `.pdf .docx .txt .pptx`
- Archives → `.zip .rar .tar .gz`
- Code → `.py .js .java .cpp .html .css`
- Others → anything not recognized

## 🚀 How to use

```bash
python organizer.py
